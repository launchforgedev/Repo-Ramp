GETTING STARTED

Quick Start

Get started with RepoRamp in a few minutes. Install the package, analyze your first Python repository, and explore its architecture through clear, actionable reports.

Installation ↓Run your first analysis ↓GitHub repository ↗

What you need

You only need a Python project and a terminal. RepoRamp reads Python source to map structure and dependencies; it does not execute the source files it analyzes.

Py
Python 3.10+

Use a supported Python environment.

$_
A terminal

PowerShell, Command Prompt, or your usual shell.

Step 1: Install RepoRamp

Install the published package with pip. A virtual environment is recommended for project isolation.

Terminal 
python -m pip install reporamp
✓
Using a virtual environment?

On Windows PowerShell, create one with py -m venv .venv and activate it with \.venv\Scripts\Activate.ps1.

Step 2: Check your setup

Confirm Python and RepoRamp are available in the active environment.

Terminal 
python --version
reporamp version
reporamp analyze --help

If the command is not found, check that the environment where you installed the package is active.

Step 3: Analyze your first repository

Change into the root directory of the Python project you want to inspect, then run the analyzer.

Terminal 
cd path/to/your-project
reporamp analyze .

RepoRamp scans Python modules, maps internal dependencies, detects configured quality issues, and creates reports.

Typical output files
reporamp-report/
├── report.md
└── report.json
i
Markdown and JSON

Use Markdown for a human-readable walkthrough and JSON when processing results with scripts or other tools.

Step 4: Customize your analysis

Pass options directly to the CLI or set project defaults in pyproject.toml.

Terminal 
# Markdown only
reporamp analyze . --format md

# Choose an output directory
reporamp analyze . --output build/reporamp

# Exclude paths
reporamp analyze . --exclude tests --exclude "migrations/*"

Project configuration

pyproject.toml 
[tool.reporamp]
max_deps = 8
max_fan_in = 10
max_module_lines = 1000
max_function_lines = 100
exclude = ["tests", "migrations/*"]
fail_on = ["QR003", "QR002"]
format = "both"
OptionPurpose
--formatChoose md, json, or both.
--outputChoose the report directory.
--exclude PATTERNSkip matching paths; repeatable.
--strictExit 1 when a file cannot be parsed.
--fail-on RULESExit 2 when selected findings exist.

Understand your report

The report gives you a practical overview of your codebase structure.

01
Architecture graph

See internal module dependencies and circular import paths.

02
Coupling metrics

Inspect fan-in, fan-out, and instability to understand dependency pressure.

03
Code inventory

Review modules, imports, classes, functions, and unresolved imports.

04
Quality findings

Review rule IDs and structural signals worth investigating.

Quality rules

These checks guide refactoring and code review. Treat findings as signals to investigate, not automatic proof of a defect.

RuleFindingWhat it flags
QR001Empty modulePython modules with no meaningful content.
QR002High fan-outToo many outgoing internal dependencies.
QR003Dependency cycleCircular dependencies in the module graph.
QR004High fan-inModules imported by many internal modules.
QR005Orphan moduleModules with no internal importers; recognized entry points are skipped.
QR006Oversized codeModules or functions over configured line-count thresholds.

Automate checks in GitHub Actions

Run RepoRamp on pull requests to catch selected structural issues before merging. Confirm action inputs and release tags in the repository before adopting this example.

.github/workflows/reporamp.yml 
name: RepoRamp
on: [pull_request]
jobs:
  reporamp:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: launchforgedev/Repo-Ramp@main
        with:
          fail-on: QR003,QR002
          args: --max-deps 8

Optional AI architecture summary

The optional Claude integration adds an AI-generated architecture summary. It is opt-in and disabled by default.

Terminal 
python -m pip install "reporamp[ai]"
# Set ANTHROPIC_API_KEY in your environment
reporamp analyze . --ai
i
Review data handling

Check the current repository documentation and privacy requirements before enabling an external AI provider.

Local Ollama chat

Ask questions about a repository using a local Ollama model. Install the optional extra and ensure Ollama is running with at least one model downloaded.

Terminal 
python -m pip install "reporamp[ollama]"
ollama list
reporamp analyze . --ask

You can also start a chat from an existing report with reporamp chat. Specify --model to select a local model. Check your installed version's help output for supported options.

MCP server

The optional Model Context Protocol integration allows compatible AI clients to query repository structure through RepoRamp tools.

Terminal 
python -m pip install "reporamp[mcp]"
reporamp mcp

See the current repository instructions for client-specific configuration and the tools available in your installed version.

Compare reports

Generate JSON reports for two revisions and compare them to identify new structural issues.

Terminal 
reporamp analyze . --format json -o base-report
reporamp analyze . --format json -o head-report
reporamp diff base-report/report.json head-report/report.json --fail-on-new

Contribute to RepoRamp

Bug reports, documentation improvements, and pull requests are welcome. Run tests and the linter before submitting changes.

Terminal 
git clone https://github.com/launchforgedev/Repo-Ramp.git
cd Repo-Ramp
python -m pip install -e ".[dev]"
pytest
python -m ruff check .
